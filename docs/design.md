# Open by nature

A field guide to a workshop: botanical geometry meets public software.
The visual system takes its sense of scale, pauses, and object placement from
Madame Polare. It uses original typography, color, illustration, and copy.

Basteleur brings a sculpted, slightly unruly silhouette to the display type.
Apfel Grotezk provides open shapes and clear reading at smaller sizes.
Both fonts are served from this repository, with no Google Fonts dependency.

The eight-petal opening form, orbit, waveform, atom, weave, and spark are original
SVG drawings. The project plates share line weight, framing, and numbering.
Their subject and color are chosen from metadata, so new projects need no
individual artwork assignment. No illustrative assets are copied from the
reference site.

Motion is decorative. Scroll remains native; the opening bloom follows a small
scroll offset, and the typographic ribbon moves slowly. Reduced-motion users
get the complete static composition. No text or links wait for an animation.
The source HTML includes the collection before browser JavaScript runs.
